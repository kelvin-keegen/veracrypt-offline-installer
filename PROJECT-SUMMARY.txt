PROJECT OVERVIEW
================
Complete offline installation system for VeraCrypt on Ubuntu with
automated CI/CD pipeline for building deployment packages.

DEPLOYMENT METHODS
==================

Method 1: CI/CD Automated Build (RECOMMENDED)
----------------------------------------------
1. Push code to Gitea/GitHub repository
2. Workflow automatically builds packages for multiple Ubuntu versions
3. Download ready-to-use ZIP files from Actions/Artifacts
4. Transfer ZIP to offline machine
5. Extract and run install script

Advantages:
  ✓ Fully automated
  ✓ Builds for multiple Ubuntu versions simultaneously
  ✓ Includes checksums and build info
  ✓ Reproducible builds
  ✓ No manual dependency hunting

Method 2: Local Build
---------------------
1. Run: sudo ./build-local.sh
2. Transfer artifacts/veracrypt-offline-ubuntu-*.zip to offline machine
3. Extract and install

Advantages:
  ✓ No CI/CD infrastructure needed
  ✓ Complete control over build process
  ✓ Quick testing

Method 3: Manual Download
-------------------------
1. Run: sudo ./download-dependencies.sh
2. Transfer entire directory to offline machine
3. Run: sudo ./install-veracrypt-offline.sh

Advantages:
  ✓ Traditional approach
  ✓ Simple to understand
  ✓ Good for one-off installations

INSTALLATION WORKFLOW
=====================

On Offline Machine:
1. Extract ZIP package
   $ unzip veracrypt-offline-ubuntu-*.zip

2. Navigate to directory
   $ cd veracrypt-offline-installer

3. Install (choose one method):
   
   Option A - Interactive:
   $ sudo ./menu.sh
   
   Option B - Direct:
   $ sudo ./install-veracrypt-offline.sh
   
   Option C - Manual:
   $ cd debs && sudo dpkg -i *.deb
   $ cd ../veracrypt && sudo dpkg -i veracrypt-*.deb

4. Verify installation
   $ veracrypt --version
   $ which veracrypt

5. Launch VeraCrypt
   $ veracrypt

========================

  • Ubuntu 20.04 LTS (Focal)
  • Ubuntu 22.04 LTS (Jammy)
  • Ubuntu 24.04 LTS (Noble) - experimental

Kernel Modules Required:
  • dm-crypt          - Device mapper crypto
  • dm-mod            - Device mapper driver

Package Size: ~30-50 MB (varies by Ubuntu version)
Installation Time: 2-5 minutes
Disk Space Required: ~100 MB

TROUBLESHOOTING
===============

Common Issues:

Permission Denied
  → Use sudo for all installation commands

Script Won't Execute
  → Run: chmod +x *.sh

Dependencies Missing
  → Ensure Ubuntu versions match between build and target

VeraCrypt Not Found
  → Check: /usr/bin/veracrypt
  → Verify: echo $PATH includes /usr/bin

CI Build Fails
  → Check workflow logs in Actions tab
  → Verify runner has internet access
  → Check Ubuntu version compatibility

See CHECKLIST.md for detailed troubleshooting steps.
