TROUBLESHOOTING:

  Permission denied?           Add sudo before command
  Script won't run?            chmod +x *.sh
  Dependencies missing?        Match Ubuntu versions
  Can't find veracrypt?        Check /usr/bin/veracrypt

TESTING:

After installation, verify with:

  $ which veracrypt           # Should show: /usr/bin/veracrypt
  $ veracrypt --version       # Should show version number
  $ lsmod | grep dm_crypt     # Should show loaded module
